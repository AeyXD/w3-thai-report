ถึงทีม w3tu — เรื่องที่พบในชีตคำแปล 3 เรื่อง

13 พฤศจิกายน 2026 · อ้างอิงชีต w3tu หลัก แท็บ v3 ตามข้อมูลล่าสุดวันนี้ · ภาษาอังกฤษอ่านจากเกม 5.0.16.41566

สวัสดีครับทีม w3tu ขอบคุณสำหรับงานแปลที่ทำให้เล่น The Witcher 3 เป็นภาษาไทยได้ครับ

ช่วงที่ผ่านมา ผมทำชีตคำแปลสำหรับใช้เองเป็นชีตเสริมในตัวติดตั้ง ThaiW3Setup ใช้เวลาแปลและตรวจแก้ราว 1 เดือน ขอแจ้งวิธีทำตามตรง: ใช้ ChatGPT ช่วยแปล และใช้ Claude Code ช่วยตรวจและแก้ไข โดยตั้งมาตรฐานการแปลตามแนวของ w3tu ให้มากที่สุด (ชื่อเฉพาะ คำศัพท์ และรูปแบบตามชีตทีม) แล้วเสริมมาตรฐานของเราเอง รายละเอียดอยู่ในหัวข้อสุดท้าย ชีตอยู่ที่ คำแปล The Witcher 3 ฉบับตรวจแล้ว เผื่อเป็นประโยชน์ เลือกหยิบไปใช้ได้ตามสะดวกครับ

ตัวติดตั้งที่ใช้

เราใช้ ThaiW3Setup (โดย FordenHillson) รุ่น 0.6.0 ซึ่งเป็นตัวติดตั้ง mod แปลไทยสำหรับ The Witcher 3 รุ่น Remastered (5.x) ตัวติดตั้งนี้ใช้คำแปลของ w3tu เป็นหลัก และดาวน์โหลดจาก Google Sheets ของทีมทุกครั้งที่ติดตั้ง

ลำดับที่ตัวติดตั้งรวมคำแปล (ชุดหลังทับชุดก่อนตาม id):

  1. ชีต w3tu หลัก แท็บ v3 และ v4
  2. ชีต w3tu NextGen
  3. ชีตของกลุ่มนักแปลอีกชุด ใช้เติมเฉพาะข้อความที่ w3tu ยังไม่มี
  4. ชีตเสริมที่ผู้ใช้เปิดเอง (ทับทุกชุด ตัวล่างสุดชนะ)
  • ชีตของเรา: ใส่เป็นชีตเสริมตัวล่างสุด จึงไม่ได้แก้หรือแตะชีตของทีม
  • ซับ Storybook: ใช้ไฟล์ของ w3tu ที่มากับตัวติดตั้งเป็นต้นทาง และปรับปรุงด้วยเช่นกัน แก้ 236 จาก 266 บรรทัด (73 ไฟล์ ทั้ง subs และ altsubs) ตามแนวทางเดียวกัน คือไม่ต้องตรงตัว แต่ห้ามเปลี่ยนความหมาย และไม่ใช้คำสมัยใหม่ ส่งเข้า ThaiW3Setup แล้วใน PR #21 (รุ่น 0.5.10) ผู้ใช้ตัวติดตั้งจึงได้ฉบับปรับปรุงนี้อยู่แล้ว ส่วนไฟล์ Storybook ของ w3tu เองยังเป็นฉบับเดิม จึงแนบรายการเทียบทุกบรรทัดมาด้วย ในหน้า รายการเทียบซับ Storybook (อังกฤษ / เดิม / ใหม่ ส่วนที่ลบเป็นสีแดงขีดฆ่า ส่วนที่เพิ่มเป็นสีเขียว)
    หมายเหตุ: ซับ Storybook ใช้ชื่อตัวละครเป็นอักษรไทยตามที่ซับ Storybook ของ w3tu ใช้มากที่สุด เช่น เอเมียร์ ซึ่งต่างจากข้อความในชีตที่คงอักษรละติน เพราะเป็นซับของเสียงบรรยายในคัตซีน
  • ผลบนเครื่องเรา: เกม 5.0.16.41566 เล่นบน macOS ผ่าน Whisky และ Heroic ข้อความในเกมแปลแล้ว 99.94%

เกี่ยวกับเรื่องที่แจ้งในเอกสารนี้: จากการอ่านโค้ด ตัวติดตั้งนำข้อความจากชีตไปใช้ตามที่เป็น ไม่ได้ซ่อมแท็กหรือตัวแปรให้ ถ้าแก้ในชีตทีม ผู้ใช้ทั้ง w3tu และ ThaiW3Setup จะได้รับการแก้ไขพร้อมกันในการติดตั้งครั้งถัดไป
