ช่วงที่ผ่านมา ผมทำชีตคำแปลสำหรับใช้เองเป็นชีตเสริมในตัวติดตั้ง ThaiW3Setup ใช้เวลาแปลและตรวจแก้ราว 1 เดือน ขอแจ้งวิธีทำตามตรง: ใช้ ChatGPT (GPT-6.1 Sol) ช่วยแปล และใช้ Claude Code (Claude Opus 5.5) ช่วยตรวจและแก้ไข โดยตั้งมาตรฐานการแปลตามแนวของ w3tu ให้มากที่สุด (ชื่อเฉพาะ คำศัพท์ และรูปแบบตามชีตทีม) แล้วเสริมมาตรฐานของผมเอง รายละเอียดอยู่ในหัวข้อสุดท้าย ชีตอยู่ที่ คำแปล The Witcher 3 ฉบับตรวจแล้ว เผื่อเป็นประโยชน์ เลือกหยิบไปใช้ได้ตามสะดวกครับ

ตัวติดตั้งที่ใช้

ผมใช้ ThaiW3Setup (โดย FordenHillson) รุ่น 0.6.0 ซึ่งเป็นตัวติดตั้ง mod แปลไทยสำหรับ The Witcher 3 รุ่น Remastered (5.x) ตัวติดตั้งนี้ใช้คำแปลของ w3tu เป็นหลัก และดาวน์โหลดจาก Google Sheets ของทีมทุกครั้งที่ติดตั้ง

ลำดับที่ตัวติดตั้งรวมคำแปล (ชุดหลังทับชุดก่อนตาม id):

  1. ชีต w3tu หลัก แท็บ v3 และ v4
  2. ชีต w3tu NextGen
  3. ชีตของกลุ่มนักแปลอีกชุด ใช้เติมเฉพาะข้อความที่ w3tu ยังไม่มี
  4. ชีตเสริมที่ผู้ใช้เปิดเอง (ทับทุกชุด ตัวล่างสุดชนะ)
  • ชีตของผม: ใส่เป็นชีตเสริมตัวล่างสุด จึงไม่ได้แก้หรือแตะชีตของทีม
  • ซับ Storybook: ใช้ไฟล์ของ w3tu ที่มากับตัวติดตั้งเป็นต้นทาง และปรับปรุงด้วยเช่นกัน แก้ 236 จาก 266 บรรทัด (73 ไฟล์ ทั้ง subs และ altsubs) ตามแนวทางเดียวกัน คือไม่ต้องตรงตัว แต่ห้ามเปลี่ยนความหมาย และไม่ใช้คำสมัยใหม่ ส่งเข้า ThaiW3Setup แล้วใน PR #21 (รุ่น 0.5.10) ผู้ใช้ตัวติดตั้งจึงได้ฉบับปรับปรุงนี้อยู่แล้ว ส่วนไฟล์ Storybook ของ w3tu เองยังเป็นฉบับเดิม จึงแนบรายการเทียบทุกบรรทัดมาด้วย ในหน้า รายการเทียบซับ Storybook (อังกฤษ / เดิม / ใหม่ ส่วนที่ลบเป็นสีแดงขีดฆ่า ส่วนที่เพิ่มเป็นสีเขียว)
    หมายเหตุ: ซับ Storybook ใช้ชื่อตัวละครเป็นอักษรไทยตามที่ซับ Storybook ของ w3tu ใช้มากที่สุด เช่น เอเมียร์ ซึ่งต่างจากข้อความในชีตที่คงอักษรละติน เพราะเป็นซับของเสียงบรรยายในคัตซีน
  • ผลบนเครื่องผม: เกม 5.0.16.41566 เล่นบน macOS ผ่าน Whisky และ Heroic ข้อความในเกมแปลแล้ว 99.94%

  1. สคริปต์ตรวจทั้งชีตทุกรอบที่แก้: คำสะกดผิดที่พบบ่อย (ปฎิ ปรากฎ ใช/ใช่ ฯลฯ), ร/ล สลับ, วรรณยุกต์หรือสระผิดคำ, เครื่องหมายซ้อนหรือลำดับผิด, ข้อความวางผิดแถว (ไทยซ้ำกันแต่อังกฤษต่าง), แท็กหรือตัวแปรไม่ตรงอังกฤษ, แถวที่ไม่มีอักษรไทย
  2. ตรวจความสม่ำเสมอทั้งชีต: อังกฤษเดียวกันแต่บางแถวแปลบางแถวไม่แปล, ป้ายหรือชื่อสั้นที่แปลหลายแบบ, คำทับศัพท์ที่สะกดสองแบบ
  3. คัดด้วยคนทุกจุด: ผลของสคริปต์เป็นรายการให้พิจารณา ไม่ใช่คำตัดสิน เช่น "คนเคราะห์ร้าย" ถูกทักว่าเป็น "คนแคระ" สะกดผิด ก็แก้ตัวตรวจแทนการแก้คำ
  4. บริบทจากไฟล์เกม: แถวที่ไม่ชัดดูจาก id ที่อยู่ติดกันในเกม สคริปต์เกม และไฟล์ในเกม แยกให้ชัดว่าอะไรยืนยันแล้ว อะไรเป็นข้ออนุมาน
  5. ตรวจหลังติดตั้งจริง: เปิดไฟล์ tr.w3strings ที่ติดตั้งแล้วเทียบกับชีตทุกแถว
